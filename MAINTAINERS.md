Changes follow the change process below: editor review and a 1-day quiet period
before merge (the quiet period is a minimum gate — any reviewer may request a
longer period).

This repository holds only material intended to be read. It is private until it
is ready to be read, not a place to park things that should not be published;
work plans, version plans, ledgers and distribution material are kept elsewhere.

A substantive change to a volume bumps that volume's version. A note describing
what changed is written only once the version it supersedes has been public.
Editing and links may be committed on their own.
