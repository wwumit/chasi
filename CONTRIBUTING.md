# Contributing

This repository contains public drafts for cross-subject identity, authority,
evidence and governance in an agent society.

## Before opening a change

- Use an issue for a semantic question or a proposed new object.
- Keep implementation plans, internal ledgers, delivery material and private
  review notes outside this repository.
- State whether a change is editorial or substantive.
- Preserve the English/Chinese volume pairing, or explicitly explain why a
  document is unpaired.

## Pull requests

A pull request should state:

1. which volume or profile it changes;
2. whether the change is editorial or substantive;
3. any version impact;
4. which implementation or conformance evidence supports a new requirement;
5. any unresolved interoperability question.

A substantive change to a volume requires a version bump. Before the superseded
version has been public, iteration may be committed without a separate change
narrative. After publication, a version bump requires a concise change note.

## Evidence and external claims

Distinguish:

- a local reference implementation;
- a second implementation;
- an independently operated deployment;
- conformance evidence;
- external adoption.

An external draft, private implementation or single deployment MUST NOT be
presented as independent adoption.

## Review

The editor reviews contributions and applies the minimum one-day quiet period
before merge. Any reviewer may request a longer period or additional evidence.

By participating, you agree to follow [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
