# Code of Conduct

## Expected behaviour

- Discuss ideas and evidence, not people.
- State uncertainty and the basis for external claims.
- Respect language differences and ask for clarification before attributing
  intent.
- Keep technical disagreement reproducible and relevant to the specification.
- Do not disclose private data, credentials or security reports.

## Unacceptable behaviour

- Harassment, threats, discriminatory language or personal attacks.
- Publishing private communications or personal data without permission.
- Repeatedly presenting unverified adoption, conformance or security claims as
  settled facts.
- Deliberately disrupting review or evading the documented change process.

## Enforcement

Report conduct concerns privately to maintainer
[@wwumit](https://github.com/wwumit) through GitHub. Reports will be reviewed
with attention to confidentiality and conflict of interest.

Maintainers may request edits, remove content, restrict participation or close
contributions when this code is violated.
